# SHURE SHORT

A mobile-first, browser-only number-pattern dashboard. Open `index.html` directly in a modern browser; no build step, dependencies, account, network calls, or unofficial data feeds are required.

## Features

- Home dashboard, BIG/SMALL and number analysis, saved-result comparison, statistics, and prediction history.
- Enter historical actual results and optionally save a snapshot of the current heuristic estimate for later comparison.
- Records persist in this browser's `localStorage`. Use **Clear my records** to delete personal entries; demo examples remain.
- Clearly marked illustrative DEMO rows are shown on first launch. They are never counted in personal win/loss or accuracy statistics.
- Analysis is based only on entered and clearly labelled demo history. Number recommendation uses the most frequent number; ties go to the most recently occurring tied number.
- Confidence is a capped, explicitly disclosed heuristic indicator, not calibrated odds or a probability of winning.

## Privacy and limitations

No results are fetched from any source. Actual results must be entered by the user. Local browser storage is device/browser-specific and may be cleared by browser settings. This tool is informational only: historical frequency does not establish future outcomes, and no prediction is guaranteed.
